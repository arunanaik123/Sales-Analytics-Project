# Business Requirements

## Objective

RetailCorp wants to analyze historical sales transactions to identify
revenue trends, customer purchasing behavior, product performance,
and sales opportunities.

## Goals

- Analyze monthly and yearly revenue.
- Identify top-performing products.
- Identify top customers.
- Understand product category performance.
- Analyze sales trends over time.
- Identify high-value orders.
- Build an interactive dashboard for business users.

## Expected Deliverables

- Normalized SQL Database
- SQL Business Analysis
- Python Exploratory Data Analysis
- Power BI Dashboard
- Executive Report
